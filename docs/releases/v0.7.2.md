# APK Pilot 0.7.2

Makes installs more reliable and failures easier to understand.

- **Stays connected through adb hiccups.** One failed device check no longer reads as "unplugged", so it cannot cancel an uninstall or move you off a page.
- **Hung adb commands stop.** Device checks time out after seconds and installs after 30 minutes instead of waiting forever.
- **Large .apks / .xapk bundles** are unpacked once, in the background, and the temporary copies are cleaned up.
- **Clearer install errors:** wrong processor (e.g. a phone build on a Quest), app too old for this Android, device Android too old, damaged or unsigned APK, install blocked on the device, and connection-helper failures now each get their own explanation and next step. File and folder names no longer affect which error is shown.

Download: `SingularityApkInstaller-win-x64-setup.exe`
