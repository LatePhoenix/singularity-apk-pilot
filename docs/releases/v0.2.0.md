# APK Installer 0.2.0

Connect the device first, then choose APK files. Halo is not bundled.

- Wizard: Welcome → connect → authorize / developer mode if needed → **choose APK(s)** → install
- Multi-select `.apk` files; installs them one after another
- Portable `adb` only — no test app in the setup
- Single-file self-contained publish so Windows Application Control does not block unsigned satellite DLLs
- Startup failures show a message instead of exiting silently
