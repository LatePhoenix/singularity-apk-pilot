# APK Pilot 0.6.0

Pilot helper always says the next step. The wizard skips Device detected when only one headset or phone is connected, and it notices when you allow this computer. Connection help covers a Meta developer account, two headset prompts, Samsung Auto Blocker, competing Android tools, and Quest 3S / Quest Pro names. USB-first Wi-Fi stays the default.
