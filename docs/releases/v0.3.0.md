# APK Installer 0.3.0

Real Quest builds: package identity, split sets, verify, and Open on device. USB-first wizard stays.

- Inspect `.apk` / `.apks` / `.xapk` for package id, version, and split name
- Group splits into one install set (`install-multiple`); sequential sets for different apps
- Verify the package on the device; optional **Open on device** (does not auto-launch)
- Use last files, Replace this app / Remove this app and install when the package id is known
- Export diagnostics on Connect, Authorization, and Developer mode
- After failed connect attempts, distinguish Windows USB presence vs empty device list
- Device picker only when two or more ready devices are connected
- Optional Authenticode via `SIGNING_PFX` or Azure Trusted Signing; Welcome can hint at a newer GitHub release
