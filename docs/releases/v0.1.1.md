# APK Installer 0.1.1

Fixes the first tester run: Quest 3 connected, but install failed because v0.1.0 had no APK (`example-app.apk` missing).

- Bundles **Halo 0.4.2** (`com.singularitysolutions.vrcmediaserver.quest`)
- Missing APK is now `MissingPayload` — no adb restart / USB false alarm
- Still self-contained win-x64 + portable `adb`

Download: `SingularityApkInstaller-win-x64-setup.exe`

The installer is not code-signed yet. Windows SmartScreen may warn; choose **More info** → **Run anyway**.
