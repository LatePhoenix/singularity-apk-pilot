# APK Installer 0.1.0

First Windows installer for testers.

- Self-contained win-x64 setup (no separate .NET install)
- Portable `adb` bundled
- Family cyan Bugdroid + visor icon
- Example `app-manifest.json` only — drop a test APK into `payloads\current\` after install to complete a device install

Download: `SingularityApkInstaller-win-x64-setup.exe`

The installer is not code-signed yet. Windows SmartScreen may warn; choose **More info** → **Run anyway**.
